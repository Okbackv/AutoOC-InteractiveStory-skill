# OC角色档案 — 星落之夜的抉择

---

## 林星河 — 星象魔法学徒

**基本资料**: 男 / 19岁 / INFJ / 11月7日 / 178cm

**外貌**: 黑发黑瞳，眉目清秀，常穿灰色法师袍。左手有一道星形伤疤——那是在他十四岁那年预言失误后，在自责中自己刻下的。目光清澈但总带着一丝忧郁，像是随时在思考什么遥远的事情。

**性格**: 林星河是一个温柔的人。这种温柔不是软弱——在需要决断的时刻，他比任何人都果断。但问题是，他总觉得自己做得不够好。十岁那年他准确预言了一场洪水，挽救了数个村庄，那是他最辉煌的童年记忆。而十四岁时，他预言了一场并不存在的灾难，整个学院紧急疏散，最终却是虚惊一场。从此他活在愧疚里。艾琳从未因此责备他，但对他来说，沉默比责骂更重。

他养成了很多小习惯来安抚自己的不安：熬夜观星、在图书馆角落躲到天亮、吹笛子的时候才能不去想那些声音。他最常说的话是"嗯……让我想想"，不是在拖延，是真的在认真思考每一个可能性和每一个后果。

**说话风格**: 温和、偏慢、会在思考时停顿。偶尔吐出一句出奇的冷幽默。习惯用"嗯……"做开场白。和亲近的人说话时会更放松，但从不失去那份自带的温和。

**能力**: 星象预言是天赋也是诅咒，因为不稳定，他每次使用都像在赌博。古籍解读是他最有信心的领域——至少书不会骗人。基础星魔法可以御光、感知星位、小范围照明和短距离传送。

**角色定位**: 主控角色 / 玩家视角

## 艾琳 — 冰霜院长

**基本资料**: 女 / 42岁 / INTJ / 3月21日 / 165cm

**外貌**: 银白长发整齐束在脑后，没有一根乱发。冰蓝色的眼眸如同她精通的法术——冷而锐利。面容冷峻，几乎从不笑，但并非因为不快乐，只是觉得没必要。深蓝绣星法袍是院长的象征，她穿上已经十年了。

**性格**: "逻辑胜过热情"是她最爱说的话，也是她活着的信条。她把一切都计算好了——实验步骤、教学计划、自己的人生。唯一的意外是五年前那场事故，她最优秀的门生在一次禁忌实验中丧生。从那以后，她的计算里多了一个不可控的变量：恐惧。她怕再失去一个学生。

她收养了林星河。在所有人看来这是善举，只有她自己知道，她在那个婴儿的眼睛里看到了和已故学生一样的星光。她对林星河格外严格，因为"放纵是对他的不负责"。深夜她会独自坐在办公室，翻看林星河的作业，眉间的纹路才稍微松动——那是她唯一允许自己流露骄傲的时刻。

**说话风格**: 精准、冷静、不留废话。不满时不会发火，而是用更冷的语气、更长的句子、更复杂的词汇把你逼到角落。但她会在你沮丧时多加一句"再来一次"——以她的标准，这就是最温暖的鼓励了。

**能力**: 冰系魔法大师级，能在瞬间冻结一片湖泊。最擅长的是解密远古魔法文献——她对秩序的追求让她在解构复杂符文时如鱼得水。

**角色定位**: 导师 / 关键NPC

## 卡修斯 — 烈火剑士

**基本资料**: 男 / 20岁 / ESTP / 8月15日 / 182cm

**外貌**: 金发永远像是刚打完一架那样微乱，褐色的眼睛里总闪着危险的光芒。轮廓分明，身形矫健，是个行动比脑子快的家伙。深红战斗法袍是他的标志，腰间从不离身的短剑上刻着家族纹章——虽然他说迟早要磨掉。

**性格**: 他是那种让你又爱又恨的人：嘴欠、冲动、不把规则当回事，但在你真正需要他的时候，他会第一个出现在你面前，刀都替你拔好了。他管林星河叫"星星"，语气像在叫自家笨弟弟。贵族出身给了他傲气，但他偏要凭实力证明自己——"卡修斯"三个字不靠家族也能震住人。

**说话风格**: 连珠炮，声音大，反问句爱好者。"这还用想？""你是不是傻？"嘴上永远在嫌弃，但每个建议都藏着真心的担忧。

**能力**: 战斗魔法和剑术双修。实战经验丰富，反应快得惊人。但一碰到理论考试就头疼。

**角色定位**: 劲敌兼挚友 / 关键NPC（特定路线出现）
