## 交互维度映射

| 节点 | 核心维度 | 说明 |
|------|---------|------|
| start | 抉择 | 三个方向代表三种价值观 |
| village_rescue | 探索 | 在燃烧村庄中寻找生机 |
| rescue_child | 抉择 | 生命vs集体利益 |
| rescue_grain | 抉择 | 集体利益vs生命 |
| library_search | 解谜 | 调查星落的真相 | 
| find_truth | 解谜 | 深入追查，发现实验失控的真相 |
| destroy_evidence | 抉择 | 选择保护某人而非真相 |
| confront_guards | 战斗 | 面对追兵的威胁 |
| fight_guards | 战斗 | 用实力说话 |
| surrender_talk | 社交 | 用语言说服对手 |
| road_ahead | 社交 | 旅途中的反思与对话 |
| go_to_ruins | 探索 | 深入禁地，直面真相 |
| return_to_academy | 社交/抉择 | 选择沉默或发声 |
| ending_hero | — | Good Ending |
| ending_fade | — | Neutral Ending |
| ending_truth | — | True Ending（条件解锁）|

## 条件路由

- **ending_truth** 需要同时满足: `know_truth == true` AND `saved_child == true`
- 不满足条件时，`return_to_academy` → `ending_fade`
- `go_to_ruins` → `ending_hero` 始终可选
